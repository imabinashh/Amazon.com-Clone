# Amazon.com Homepage Clone

A front-end static clone of the Amazon.com homepage, built from scratch as my very first web development project. This project was developed to practice fundamental layout architectures, specifically focusing on Flexbox design and documenting CSS positioning challenges.

## 🚀 Tech Stack
* **HTML5:** Semantic structuring (50.7% of the codebase)[cite: 1].
* **CSS3:** Styling, Flexbox layouts, and positioning (49.3% of the codebase)[cite: 1].

## 📂 Repository Structure
* `Amazon.html`: The main structural file containing the homepage layout[cite: 1].
* `style.css`: The stylesheet governing the visual design and Flexbox properties[cite: 1].
* `Assets/`: Directory containing all the images, icons, and graphical elements used in the UI[cite: 1].
* `Case Study/`: Contains documentation outlining the layout architecture and the specific CSS challenges encountered during development[cite: 1].

## 💡 Key Learnings
* Structuring complex, multi-section web pages using HTML.
* Utilizing CSS Flexbox for aligning navigation bars, product grids, and footer elements.
* Managing absolute and relative positioning for layered UI components.
* Organizing project assets and drafting technical case studies for LinkedIn.
